이용약관

1. 적용 범위

본 이용약관(이하 '본 약관')은 앱 '스페인어 마스터'(이하 '본 앱')의 이용 조건을 정한 것입니다. 이용자는 본 앱을 이용한 시점에 본 약관에 동의한 것으로 간주됩니다.

2. 라이선스

본 앱은 이용자 개인에게 비독점적으로 이용할 권리를 부여합니다. 본 앱의 이용에는 Apple의 '라이선스 계약(Licensed Application End User License Agreement)'도 적용됩니다.
https://www.apple.com/legal/internet-services/itunes/dev/stdeula/

3. 목적

본 앱은 1단계부터 4단계까지의 스페인어 어휘 학습과 문법 학습을 보조하는 것을 목적으로 합니다. 특정 시험의 합격을 보증하지 않습니다.

4. 무료로 이용할 수 있는 범위

다음 기능은 결제 없이 계속 이용하실 수 있습니다.
• 1단계 전체 단어(1,667개) 학습과 그림 해설
• 1단계 문제집(410문제, 4지선다·해설 포함)과 듣기(100문제)
• 스페인어 문법 강좌 제1부~제3부(전 21장)
• 학습 진도 기록, 단어장, 검색

5. 구독(Pro 플랜)

Pro 플랜을 구독하면 2단계·3단계·4단계 단어(3,889개), 문제집(1,502문제)과 듣기(310문제), 문법 강좌 제4부~제8부(39장)가 해제됩니다.

[플랜과 가격]
· 연간 플랜: 1년에 한 번 결제(7일 무료 체험 포함)
· 월간 플랜: 한 달에 한 번 결제
가격은 구독하기 전에 앱과 App Store에서 현지 통화로 표시됩니다.

[자동 갱신 안내]
· 요금은 구매 확정 시 Apple ID 계정으로 청구됩니다.
· 구독은 자동으로 갱신됩니다. 현재 기간이 끝나기 최소 24시간 전까지 자동 갱신을 끄지 않으면 같은 금액으로 자동 갱신됩니다.
· 갱신 요금은 현재 기간이 끝나기 전 24시간 이내에 계정으로 청구됩니다.

[해지 방법]
iPhone의 ‘설정’ → 맨 위의 Apple ID 이름 → ‘구독’에서 언제든지 해지할 수 있습니다. 해지하더라도 이미 결제한 기간이 끝날 때까지는 Pro 플랜을 이용하실 수 있습니다.

[무료 체험]
연간 플랜에는 7일 무료 체험이 있습니다. 무료 기간이 끝나기 최소 24시간 전까지 해지하지 않으면 연간 요금이 청구됩니다. 무료 체험 기간이 남아 있더라도 구독을 구매하면 남은 기간은 소멸됩니다.

[교환 코드(오퍼 코드)]
개발자가 발행한 교환 코드가 있는 경우, 앱 내 ‘설정 → 코드 사용하기’ 또는 App Store 앱의 ‘기프트 카드 또는 코드 사용’에서 입력하면 코드에 설정된 기간 동안 Pro 플랜을 이용하실 수 있습니다. 코드에 의한 무료 기간이 끝난 후에는 정상 요금으로 자동 갱신됩니다(자동 갱신을 원하지 않으시면 무료 기간이 끝나기 최소 24시간 전까지 해지해 주세요). 코드의 발행 및 만료는 개발자의 재량에 따릅니다.

[환불]
구매 후 환불은 Apple이 정한 정책에 따릅니다. 개발자가 직접 환불해 드릴 수는 없습니다.
